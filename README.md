- Présentation de projet:
BusDirect est une application web qui permet de gérer les réservation des siéges,ajouter ,modifier et supprimer les réservations des passagers.
 -Objectif de projet:
.pratiquer HTML, CSS et JAVASCRIPT.
.pratiquer DOM en javascript
.validation les formulaires
 -Fonctionnalites/
 .Afficher les siéges et sont status si occupés ou disponibles.
 .réserver un siége
 .modifier un réservation;
 .supprimer une réservation
 .afficher message succés ou erreur
 .afficher les compteurs des siéges disponible et le prix le ticket
